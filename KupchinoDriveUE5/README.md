# Kupchino Drive UE5 🥶🚗

Первый 3D-прототип отдельной игры на Unreal Engine 5.6.

## Уже заложено
- 3D-машина от третьего лица.
- Аркадная физика: разгон, торможение, задний ход, поворот и столкновения.
- Процедурный город из простых 3D-блоков без внешних ассетов.
- Три больших района: Kupchino, Nordland и Southport, соединённые трассой.
- Парковочные миссии: приехать в отмеченную точку и остановиться.
- Награда $500 за выполненную парковку.
- Миникарта: голубая точка = игрок, жёлтая = парковка.
- Свободный режим.
- Новая случайная миссия.
- Android package id: com.kupchino.drive.

## Управление прототипом
W/S или стрелки вверх/вниз — газ и задний ход.
A/D или стрелки влево/вправо — рулить.
M — миссии / свободный режим.
N — новая парковочная миссия.

## Как открыть
1. Установить Unreal Engine 5.6 с поддержкой Android.
2. Открыть `KupchinoDrive.uproject`.
3. Если Unreal предложит собрать C++ модуль — согласиться.
4. Нажать Play.
